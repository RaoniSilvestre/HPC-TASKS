# Computação de alto desempenho

Atividades relacionadas a disciplina de programação de alto desempenho ministrada pelos professores Samuel Xavier e Carla Santana.

## Estrutura do repositório

O repositório é organizando por tasks, cada task passada em sala se referencia a uma pasta no repositório.

Cada pasta tem 4 arquivos:

- `relatorio.pdf`: Arquivo PDF final utilizado como relatório da atividade.
- `main.typ`: Arquivo typst utilizado para gerar o PDF do relatório.
- `main.c`: Implementação da atividade requerida.
- `TASK.md`: Enunciado da atividade.
